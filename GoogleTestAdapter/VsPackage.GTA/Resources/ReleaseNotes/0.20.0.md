This release of the [fork](https://github.com/snargit/GoogleTestAdapter) closes the remaining gaps to Microsoft's *Test Adapter for Google Test* and supports Windows on ARM. See the [README](https://github.com/snargit/GoogleTestAdapter#about-this-fork) for details.

* enhancement: the VSIX contains the *Google Test* project and item templates, which so far were only part of Microsoft's *Test Adapter for Google Test* (which has to be removed to use GTA); the wizard of the project template optionally references the project to be tested and adds one of the Google Test NuGet packages
* enhancement: Windows on ARM: GTA can be installed into the ARM64 versions of Visual Studio 2022 and 2026 and reads the symbols of test executables in ARM64 processes; the Google Test NuGet packages and the project template support platform ARM64
* enhancement: releases contain a VSIX per Visual Studio version, which only differ in the Google Test NuGet packages the project template adds: `GoogleTestAdapter-<version>.vsix` for Visual Studio 2017 to 2026 (packages built with the v143 toolset), and `GoogleTestAdapter-<version>-vs2026.vsix` and `GoogleTestAdapter-<version>-vs2026-arm64.vsix` for Visual Studio 2026 only (packages built with v145); the Google Test NuGet packages of both toolsets are also available separately
* enhancement: failures of `SetUpTestSuite()` are reported by the tests of the suite (which Google Test skips), and failures of `TearDownTestSuite()` by a test `TearDownTestSuite` of the suite (option *TearDownTestSuite test cases*); before, these failures were only visible in the test output
* enhancement: new option *Additional test discovery parameters*, which replaces the *Additional test execution parameters* for test discovery
* bugfix: the output of test executables writing to both standard output and standard error was processed concurrently, which could garble or lose test results
* bugfix: names of tests, suites, and namespaces containing characters such as Devanagari vowel signs or Roman numerals (`Ⅰ`) were truncated, so that their tests could not be run
