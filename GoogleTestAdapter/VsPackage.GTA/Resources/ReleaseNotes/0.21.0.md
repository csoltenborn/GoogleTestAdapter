This release of the [fork](https://github.com/snargit/GoogleTestAdapter) makes GTA accessible to scripts and MCP servers via Visual Studio's automation model (DTE). See the [README](https://github.com/snargit/GoogleTestAdapter#about-this-fork) for details.

* enhancement: GTA's automation object `DTE.GetObject("GoogleTestAdapter")` provides, as JSON, the run settings GTA gives Test Explorer, the settings GTA uses for an executable, whether GTA would discover the tests of an executable and why, and the tests GTA discovers, with source locations, namespaces, traits, and CTest test properties (`Tools/AutomationExample.ps1` shows its use)
* enhancement: GTA's options are available as `DTE.Properties("Google Test Adapter", "<page>")`, which never worked so far, and the toolbar commands as `GoogleTestAdapter.ToggleCatchExceptions`, `GoogleTestAdapter.ToggleBreakOnFailure`, `GoogleTestAdapter.ToggleParallelTestExecution`, and `GoogleTestAdapter.TogglePrintTestOutput`
* enhancement: the release notes shown after an update follow Visual Studio's color theme, open links in the default browser, and no longer ask for donations
* enhancement: executables blocked since they are located on a network drive are reported as such (rather than as having come from another computer, to be unblocked)
* bugfix: test durations, which GTA uses to schedule tests, were lost if several processes (e.g. test hosts running in parallel) updated the durations of an executable at the same time
