This is the first release of the [fork](https://github.com/snargit/GoogleTestAdapter) supporting Visual Studio 2022 and 2026. See the [README](https://github.com/snargit/GoogleTestAdapter#about-this-fork) for details.

* **breaking change**: GTA requires Visual Studio 2017 or later and .NET Framework 4.6; Visual Studio 2013 and 2015 are no longer supported
* enhancement: GTA can be installed into Visual Studio 2022 and 2026; Google Test, the Google Test NuGet packages and the sample projects have been updated to Google Test 1.18.0
* enhancement: the CTest test properties `LABELS`, `DISABLED`, `TIMEOUT`, `WORKING_DIRECTORY` and `ENVIRONMENT` are honored (can be switched off with option *Use CTest test properties*)
* enhancement: the solution settings file and `$(SolutionDir)` are supported in Open Folder mode
* enhancement: test executables linking Google Test or Google Mock as DLLs are discovered, whatever the DLLs are named and also if they are delay-loaded
* enhancement: Test Explorer groups tests by their C++ namespace ([#342](https://github.com/csoltenborn/GoogleTestAdapter/issues/342), [#365](https://github.com/csoltenborn/GoogleTestAdapter/issues/365))
* enhancement: tests have source locations even without .pdb file or if they have been registered at runtime, provided by Google Test 1.8.1 or later ([#309](https://github.com/csoltenborn/GoogleTestAdapter/issues/309))
* enhancement: option *Debugger engine* has new choice *Managed (.NET Core, .NET 5+) and native*, which allows to debug into .NET Core and .NET 5+ code, while *Managed and native* only supports the .NET Framework ([#317](https://github.com/csoltenborn/GoogleTestAdapter/issues/317))
* enhancement: Test Explorer shows the instances of typed and parameterized tests below a common node ([#210](https://github.com/csoltenborn/GoogleTestAdapter/issues/210))
* enhancement: Visual Studio's code coverage (*Test → Analyze Code Coverage*) covers Google Test executables without further configuration, and GTA's assemblies are excluded from the results
* enhancement: new options *Source path mapping* and *Map only missing source paths* make test locations and failure stack traces of executables built elsewhere (e.g. by CI) navigable
* enhancement: new option *Test timeout in s*: tests running longer are killed and reported as failed, and the remaining tests are run
* enhancement: test case filters support the properties `ClassName`, `Name` and `Namespace`
* enhancement: tests compiled with `/utf-8` are supported
* enhancement: new trait macros headers for Google Test 1.10.0 to 1.18.0 ([#349](https://github.com/csoltenborn/GoogleTestAdapter/issues/349); the Google Test NuGet packages contain the header as `GTA_Traits.h` ([#316](https://github.com/csoltenborn/GoogleTestAdapter/issues/316)))
* enhancement: the error message of a crashed test contains the exit code of the test executable ([#358](https://github.com/csoltenborn/GoogleTestAdapter/issues/358))
* enhancement: the output of tests is reported as the results' standard output ([#341](https://github.com/csoltenborn/GoogleTestAdapter/issues/341)); the error message starts with the first failure, and failures without source location (`unknown file: error:`) are recognized
* enhancement: test results are easier to process for tools like Copilot: stack trace entries are labeled with the test's name, crashed and timed out tests point to the test's source location, and skip messages are reported
* enhancement: GTA warns if Microsoft's *Test Adapter for Google Test* is installed, about undefined environment variables in options ([#357](https://github.com/csoltenborn/GoogleTestAdapter/issues/357)), and about missing .pdb files
* enhancement: test runs use the current solution and configuration of Visual Studio ([#363](https://github.com/csoltenborn/GoogleTestAdapter/issues/363)), and the package is loaded if Visual Studio is started with a solution or folder ([#364](https://github.com/csoltenborn/GoogleTestAdapter/issues/364))
* bugfix: canceling a test run kills the test executable including all processes it has started ([#337](https://github.com/csoltenborn/GoogleTestAdapter/issues/337))
* bugfix: the Google Test NuGet packages choose debug or release libraries by CRT rather than configuration name ([#356](https://github.com/csoltenborn/GoogleTestAdapter/issues/356))
* bugfix: test suites with dots in their names no longer cause tests of other suites to be run ([#330](https://github.com/csoltenborn/GoogleTestAdapter/pull/330))
* bugfix: test case filters on traits with multiple values match
* bugfix: test executables with paths not representable in the ANSI code page are discovered ([#288](https://github.com/csoltenborn/GoogleTestAdapter/pull/288))
* bugfix: test results are no longer lost if test names contain non-ASCII characters
* bugfix: tests skipped with `GTEST_SKIP()` are no longer reported as passed if their results are taken from the result XML file
